# 🛒 E-Commerce Website

A modern, responsive and user-friendly **E-Commerce Website** built with **Python, Django, SQLite and modern frontend technologies**.

The project provides a complete online shopping experience where users can browse products, view product details, manage their cart, place orders and maintain their purchase history.

---

## 🚀 Live Demo

🌐 **Live Website:**
https://e-commers-website-qnbd.onrender.com

## 📌 Project Overview

This E-Commerce Website is designed as a full-stack web application using Django.

The main goal of this project is to provide a clean, responsive and practical online shopping platform with features such as:

* User registration and login
* Product categories
* Product browsing
* Product details
* Shopping cart
* Order placement
* Purchase history
* Responsive design
* Admin product management
* User account management

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/GorNarendrasinh/E-commers-website.git
```

### 2. Open the Project

```bash
cd E-commers
```

### 3. Create Virtual Environment

Windows:

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Git Bash:

```bash
source venv/Scripts/activate
```

Windows CMD:

```cmd
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run Database Migrations

```bash
python manage.py makemigrations
```

```bash
python manage.py migrate
```

### 7. Create Admin User

```bash
python manage.py createsuperuser
```

Enter:

```text
Username
Email
Password
```

### 8. Start Development Server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
